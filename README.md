# GramPay — Voice-First UPI for Rural India
### National Buildathon 2026 | Fintech for Bharat

## Short Description (for submission — 198 words)

GramPay is a voice-first UPI payment solution built for India's 450M+ rural citizens who are excluded from digital payments due to language barriers and low digital literacy.

**The Problem:** Existing UPI apps are English/Hindi-only, text-heavy, and designed for urban users. Rural Indians — farmers, women SHG members, kirana owners — cannot use them.

**What We Built:** A web-based MVP demonstrating GramPay's core voice payment flow:
- 🎙️ Voice command input in 12 Indian regional languages (Hindi, Marathi, Tamil, Bengali, Telugu, Bhojpuri + more)
- 🤖 NLP-based intent parsing — extracts recipient name, amount, and transaction type from natural speech
- 🔊 Audio confirmation before every payment — reduces fraud and errors
- 📱 Mobile-first UI designed for low-literacy users
- 💰 Balance inquiry via voice
- 🌐 Works on low-bandwidth networks

**Tech Stack:** HTML5, CSS3, Vanilla JavaScript, Web Speech API (Speech Recognition + Text-to-Speech), Google Fonts

**Impact:** Targets ₹2.5T rural fintech market growing at 28% CAGR. Aligned with PMJDY, Jan Dhan, and NSDC rural skilling initiatives.
